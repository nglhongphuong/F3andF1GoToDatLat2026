    👥 Người tham gia

    🔒 Tên + vai trò lưu công khai trong data.txt. SĐT và địa chỉ nhà được mã hoá bằng mật khẩu nhóm trước khi lưu, người ngoài mở web/GitHub chỉ thấy chuỗi mã hoá.

    🗄️ Dữ liệu (data.txt)

    Mọi thay đổi (thêm/sửa/xoá thẻ, tick xong, thành viên...) đều ghi vào data.txt. Refresh vẫn còn vì bản nháp được giữ trong máy. Bấm Lưu lên GitHub để ghi thẳng vào file data.txt trên repo, cả nhóm cùng thấy.
    👥 Người tham gia
    ⚙️ Kết nối GitHub (làm 1 lần)
    Tạo token: GitHub → Settings → Developer settings → Fine-grained tokens → chỉ chọn repo này, quyền Contents: Read and write. Token chỉ lưu trong trình duyệt của bạn, đừng chia sẻ.
